## 🚀 Sobre mí

Disfruto verdaderamente participar en **todas las etapas** del desarrollo: entender el problema, diseñar la arquitectura, implementar frontend y backend, modelar bases de datos, desplegar infraestructura y mantener el producto en producción.

También dedico buena parte de mi tiempo a la **ciberseguridad**. Tengo formación en hacking ético y practico regularmente análisis de vulnerabilidades, laboratorios y desarrollo de herramientas propias para automatizar tareas de pentesting. Aplico este conocimiento para construir aplicaciones más seguras desde el diseño.
